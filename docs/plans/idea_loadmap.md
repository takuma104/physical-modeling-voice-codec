# PMVC-TTSロードマップ

## Version1(V1):
- CHIMERAエンジンは改造しない
- 日本語と英語のG2PありのTTS実装
- 話者の調整は2次元の値の設定による 平均f0と声の明るさ(こもる←→明るい) 必須ではないが発話中にいじれると面白そう
- WebUIはCHIMERAのSpeak画面を参考に作り直したもの。ぱっと見CHIMERAの画面そのものだと、ユーザーはオリジナルのCHIMERAと差がよく分からない可能性があり、たとえばオリジナルのDarkテーマからLightテーマに変えるなど、違いを分かり易くしたい　(コピーの別のものを作りたいという意図ではなく、区別を分かりやすくつけたいという意図。もちろんオリジナルへのリンクもわかりやすく欲しい)
- デモWebUIサイト: ユーザーは特段のインストールなしでVercelもしくはHuggingFace Spaceで動いてるのを使えるようにしたい
- モデルウェイトはCCライセンスでhuggingfaceで配布したい(学習データはCC-BYライセンスのデータのみに依存した形にしたい)
- コードの配布リポジトリへの登録は特に必要なく、githubのリポジトリcloneでローカルで動くようにできればOK
- テクニカルレポートもV1の内容までのものを反映する。基本は現状ままで良く、公開版について作業した分を追記する形でOK

## Version2(V2):
- CHIMERAエンジンの改良含む(鼻声対策等) よりリアルな音声生成に必要な要素の研究含む
- 日本語と英語のG2Pなしの推論(PocketTTSのFlowMLのアーキテクチャを流用等)
- 話者の調整は、参照音声からの自動生成を追加
- WebUI: 参照音声の指定の追加、参照音声のサンプル追加
- V2用のテクニカルレポートを新規で作成(V1を参照しつつ)
